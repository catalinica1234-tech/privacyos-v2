# Manual de uso

1. Abre el panel y elige **Nuevo análisis**.
2. Ingresa la URL pública de un sitio de prueba, por ejemplo `https://example.com`, y selecciona los marcos que quieras consultar.
3. Tras el guardado, abre el informe y revisa **Hallazgos** y **Evidencias**. Desde **Historial** puedes volver al informe y recargarlo.
4. En el panel, el asistente explica conceptos como cookies o consentimiento. En un informe guardado puede explicar observaciones y sugerir qué revisar primero.

El espacio de trabajo depende de la cookie del navegador. Usa el mismo perfil para volver a tus análisis y datos ficticios para la evaluación.

| Si ocurre | Qué hacer |
|---|---|
| La URL no se acepta | Comprueba que empieza con HTTPS o HTTP y pertenece a un sitio público. |
| El servidor no puede guardar | Espera a que vuelva PostgreSQL y usa **Reintentar**. |
| El asistente está ocupado o apagado | Consulta **Hallazgos** y **Evidencias** y vuelve a intentar más tarde. |
