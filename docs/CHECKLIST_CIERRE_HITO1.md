## Verificaciones antes de exponer
1. Abrir el HTML en un navegador y avanzar por todas las diapositivas con botones y teclado.
2. Confirmar que el mapa y la arquitectura se vean completos y legibles.
3. Abrir https://privacyos-v2.vercel.app/app/dashboard y comprobar Dashboard → Nuevo análisis → Progreso → Informe.
4. Preparar una URL pública de prueba y un informe de respaldo por si la red falla.
5. Ensayar el guion con cronómetro y mantener la exposición dentro de cinco minutos.
6. Confirmar que el PDF contenga las mismas láminas que se proyectarán.

## Exactitud
- Presentar PRIVACYOS como un único producto.
- Describir como existentes solo las capacidades demostrables.
- No afirmar crawling exhaustivo, certificación legal, autenticación multiusuario ni base de datos compartida si no están implementados.
- No inventar fuentes, métricas, pruebas ni integrantes.
