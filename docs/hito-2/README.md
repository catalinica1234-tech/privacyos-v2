# Hito 2 · Backend

## Espacio de entrega

Los materiales definitivos están pendientes de incorporación por los integrantes del equipo que preparan cada pieza. La distribución de nombres y responsables queda a cargo del equipo.

| Carpeta | Archivo esperado | Contenido |
|---|---|---|
| [informes](entregables/informes/) | `hito-2-informe-tecnico-v1.pdf` | PDF aprobado del hito. |
| [anexos](entregables/anexos/) | `hito-2-anexo-<tema>-v1.pdf` | Anexos aprobados que se entreguen por separado. |
| [presentaciones](entregables/presentaciones/) | `hito-2-presentacion-v1.pdf` | Láminas aprobadas para compartir. |
| [videos](entregables/videos/) | `hito-2-demo-crud-v1.mp4` o `hito-2-video-enlace.md` | Video aprobado o ficha de enlace, si corresponde. |
| [capturas](entregables/capturas/) | `hito-2-crud-<operacion>-01.png` | Capturas aprobadas de la demostración, con recurso, operación y resultado visibles, usando datos ficticios. |

La documentación complementaria aprobada va en [complementos](entregables/complementos/), si corresponde, como `hito-2-complemento-<tema>-v1.pdf` o el formato original. Las rutas preparadas conservan únicamente marcadores hasta que el equipo incorpore los archivos aprobados. Consulta las [convenciones de nombres y revisión](../colaboracion.md).
