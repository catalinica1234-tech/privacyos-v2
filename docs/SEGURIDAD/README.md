# Seguridad y datos personales

La [documentación técnica de seguridad](seguridad.md), la [auditoría inicial](../audit/auditoria-forense.md) y los [casos de prueba](../pruebas/README.md) sirven como antecedentes para el Anexo D de INGT1003.

La revisión distingue el workspace anónimo por cookie de una identidad de usuario con cuenta. La rama de integración incorpora la corrección de aislamiento de `seguridad/aislamiento-workspace`. La disponibilidad de la interfaz pública no acredita el aislamiento ni la persistencia en producción.

Antes de publicar el índice, revisar documentos y capturas con datos personales. Se detectó un PDF académico con identificadores en portada. El original debe conservarse y una eventual versión anonimizada corresponde a sus autores, con el manejo de acceso correspondiente. Para la evaluación se usan datos ficticios.

El cierre del Hito 3 requiere un análisis del tratamiento de datos y medidas realmente aplicadas, y la declaración de herramientas de IA, partes asistidas y verificación. Estas notas orientan la revisión del equipo.
