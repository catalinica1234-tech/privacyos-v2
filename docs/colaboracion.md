# Incorporación de entregables

Usa el índice del [Hito 1](HITO_1/README.md), [Hito 2](HITO_2/README.md) o [Hito 3](HITO_3/README.md) para ubicar el material. La grabación promocional corresponde al [Hito 3](HITO_3/video-promocional/) y dura hasta dos minutos.

Nombra los archivos nuevos con minúsculas y guiones, por ejemplo hito-3-anexo-uso-ia-v1.pdf. Conserva los nombres originales. Cuando se apruebe una entrega, actualiza su enlace en el README del hito. Para un video externo, agrega una ficha con título, duración y enlace. Revisa el acceso y la presencia de datos personales antes de compartir.

Las [evidencias técnicas](evidencias/README.md) se mantienen junto a sus referencias de origen.
